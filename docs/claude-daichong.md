> **立场说明：** 整理：瑶瑶ai训练师。作者自己经营一家 AI 会员代充商城（kw.yaoyao.chat），所以本文不是第三方评测；作者商城的价格、开通流程和售后统一放在 [作者商城商品说明](shangcheng.md)。与 OpenAI、Anthropic、Google、xAI 没有隶属关系，也没有授权，品牌名仅用于说明。

正本讲 Claude Pro、Max 在国内的四种开通方式：claude.ai 网页订阅、iOS / 安卓 App 内购、官方赠送订阅、第三方代充。事实部分只取 Anthropic 官方页面，2026-10-26 核对。仓库里另有两个专题子页，一页讲代充原理和风险，一页专讲 Max 两档。

[官方价格](https://github.com/haiwaihuyonghui-rgb/claude-daichong#claude-官方价格)：Pro 月付每月 20 美元，也可以年付一次 200 美元（折合每月 17）；Max 5x 每月 100 美元、Max 20x 每月 200 美元，只能月付，标价都不含税。Max 的用量是 Pro 的 5 倍或 20 倍，另附每月 100～200 美元的 API 额度；Pro 和 Max 都包含 Claude Code。官方帮助中心特别说明这些是网页价，手机 App 内的价格可能不一样。

几条关键规则：Anthropic 的支持地区不含中国大陆、香港、澳门，台湾在；网页订阅的付款方式写的是信用卡，没有支付宝、微信；App 内订阅的付款、收据和取消都要在应用商店里办。官方的[赠送订阅](https://github.com/haiwaihuyonghui-rgb/claude-daichong#方法三礼品卡--赠送订阅)目前对所有账号暂停购买，所以市面上叫"Claude 礼品卡"的东西，要先问清到底是什么。代充不绑你的卡、不会自动续费，但不能找 Anthropic 退款，也享受不到官方年付的折扣。

怎么选档：第一次买先选 Pro；Pro 经常碰到上限，再换 Max 5x；几乎全天在跑 Claude Code 的，再考虑 Max 20x，拿不准就先用一周看看。正本还单独写了[封号风险与申诉](https://github.com/haiwaihuyonghui-rgb/claude-daichong#封号风险与申诉)：常见诱因是在不支持的地区使用、频繁切换网络所在国家、多人共用、用脚本批量调用网页版、用虚拟号码或一次性邮箱注册；被封后先看邮箱里的官方通知，按指引申诉。文末有四种方法的横向比较、常见问题和复测记录。
