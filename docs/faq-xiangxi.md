正本是 ai-subscription-guide-cn 仓库里的常见问题详细版，18 个问答分成四组：能不能用、关于代充、关于档位、关于这个仓库本身。它给自己定了规矩：只写公开可核实的信息和售后经验，不写本币价格、不放购买入口，并在开头说明作者同时提供代充服务。

[能不能用](https://github.com/haiwaihuyonghui-rgb/ai-subscription-guide-cn/blob/main/docs/faq.md#关于能不能用)一组讲清三件事。ChatGPT 和 Claude 的官方支持名单都不含中国大陆，从未列出的地区访问可能导致账号受限，正本只说事实、不提供绕过方法。国内发行的 Visa、万事达卡常被拒，关键在发卡地区，而不是卡组织。官网也不收支付宝等国内支付方式，能用这些付款的都是第三方渠道，钱付给的也是第三方。

[关于代充](https://github.com/haiwaihuyonghui-rgb/ai-subscription-guide-cn/blob/main/docs/faq.md#关于代充)一组篇幅最长。正本认为封号主要看钱从哪来、账号怎么用，低价单付款被撤销、订阅被收回，才是"代充被封"的主要来源。正规代充只要账号邮箱，自助开通再加一段登录信息，不要密码和验证码；用平时的账号看到会员标识、聊天记录都还在，才算开在自己账号上。另外几条：代充不能向官方退款、不会自动续费；通道暂停时卡密一般会退回，别连续重复提交；能不能开发票各家不同，要事先问。

[关于档位](https://github.com/haiwaihuyonghui-rgb/ai-subscription-guide-cn/blob/main/docs/faq.md#关于档位)一组给出升档顺序：先用低一档一个月，常撞额度再升；Claude Code 已含在 Pro / Max 里，不用另买；年付要看能不能用满一年；一个账号不要多人共用。最后一组[关于本仓库](https://github.com/haiwaihuyonghui-rgb/ai-subscription-guide-cn/blob/main/docs/faq.md#关于本仓库)解释作者是卖家、内容为什么仍可参考：事实都带来源，评判代充的那 8 条也同样拿来要求作者自己，目标是每两周核对一次官方价格和地区页。
