这一章对应的正本回答一个问题：人在国内，想给自己的账号开 ChatGPT Plus，有哪几条路、各要什么条件。正本把能走的路归成四类——chatgpt.com 网页订阅、苹果 / 谷歌应用内购、OpenAI 官方礼品卡、第三方代充，逐一写清条件、优缺点和风险，事实部分都附 OpenAI 帮助中心的链接和核对日期。

先记住几条官方事实（2026-10-26 核对，详见正本的 [ChatGPT 官方价格](https://github.com/haiwaihuyonghui-rgb/gpt-chongzhi#chatgpt-官方价格) 一节）：Plus 每月 20 美元，只能按月付，没有年付，也不能一次预付几个月；Pro 分 100 / 200 / 500 美元三档，只有 500 那档带 Ultrafast。中国大陆、香港、澳门不在 OpenAI 的支持地区名单里，台湾在。官网结算只写了接受主要信用卡，没有支付宝、微信；官方礼品卡目前只在美国卖、只在美国能兑，也不能拿去做 App 内购。另外，会员费和 API 用量是两本账，开了 Plus 不等于 API 有余额。

怎么选：手里有支持地区能用的信用卡，官网订阅是最直接的路，发票、退款都归 OpenAI；有外区商店账号和余额的，可以在 App 里订，但网页和 App 各订一份会被扣两次；两样都没有、只能用支付宝或微信的，才轮到代充。代充不走你的卡、不会自动续费，代价是没法找官方退款，售后全靠卖家，所以正本给了挑卖家的 [6 个判断点](https://github.com/haiwaihuyonghui-rgb/gpt-chongzhi#怎么判断代充靠不靠谱6-个判断点) 和一份付款前一分钟自查清单，合租、成品号则明确不建议。

正本篇幅最大的部分是 [12 个常见报错](https://github.com/haiwaihuyonghui-rgb/gpt-chongzhi#报错--常见问题大全)的逐条处理，包括付款被拒、已有订阅升不了档、付了款仍是 Free、重复扣费、额度到顶、账号被停用等，每条按"现象 → 原因 → 怎么处理"写并附官方出处。此外还有 Plus 和 Pro 按用量怎么选、降低封号风险的几个使用习惯，以及按日期倒序的复测记录。
