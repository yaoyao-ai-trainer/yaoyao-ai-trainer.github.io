## 怎么开通（4 步）

1. 确认账号不是会员（免费版，见上表）。记住你平时用哪种方式登录 Grok（X、Google、Apple 或邮箱），开通后用同一种方式登录才看得到会员。
2. 在 [kw.yaoyao.chat/item/10](https://kw.yaoyao.chat/item/10?utm_source=github&utm_medium=org&utm_campaign=yaoyao-ai-trainer&utm_content=grok-daichong&utm_content=grok-daichong) 下单，页面上「选择档位」选 Plus / Premium / Super / Ultra（默认 Premium），用支付宝或微信付款。不用先加微信。
3. 付款后用**电脑浏览器**打开 grok.com 并登录要充值的账号 → 按 F12（苹果电脑 Option+Command+I）→ 顶部 Application → 左边 Cookies → https://grok.com → 找到名字叫 **sso** 的那一行，完整复制它的值（eyJ 开头的一长串），粘贴到订单页提交。订单页有同样的图文步骤。
4. 瑶瑶人工开通到你自己的账号，商品页写明 10 分钟内开通。打开 grok.com，设置或订阅页显示 Premium 就是成功了；App 里退出再登录一次。

**关于 sso 代码：** 它相当于你账号的临时登录凭证，所以只填在 kw.yaoyao.chat 的订单页，不要发给任何主动加你的"客服 / 助理"。本店不要密码，也不要手机或邮箱验证码。

## Grok 代充靠谱吗：怎么判断

不管在哪家买，付款前对照这几条：

1. **开在谁的账号上？** 应该开在你自己的 Grok 账号，不是给你一个成品号。
2. **账号条件说清楚了吗？** Grok 代充常有"只限免费版""要有某种优惠"之类的条件，正规卖家会写在商品页上，而不是付了款才告诉你。
3. **要不要密码、验证码？** 要的别买。
4. **价格离谱吗？** 官方 Premium 约 30 美元/月，远低于这个价的要问清原因。
5. **失败和掉会员怎么处理？** 规则要写在页面上。
6. **售后找得到人吗？** 要有固定、可核实的联系方式。

本店对应的做法：商品页写明账号条件；开到你自己的账号；不要密码；没开通成功重新开通或退款；本期内掉会员补一个月；封号不在质保范围、不退款。原文见 [售后与质保规则](https://kw.yaoyao.chat/guide/shouhou-zhibao.html?utm_source=github&utm_medium=org&utm_campaign=yaoyao-ai-trainer&utm_content=grok-daichong&utm_content=grok-daichong)。

## Grok 会员租赁 / 合租能不能买

不建议。会员额度按账号算，多人共用会互相抢额度；多地同时登录容易触发风控，通常也违反服务条款；聊天记录对共用的人可见。本店不卖共享号、不拼车，只开到你自己的账号。

**Q：Grok 会员充值多少钱？**

**Q：SuperGrok 和 Grok Premium 是一回事吗？**
A：是同一档。官方新出的 Super 是更高的一档（约 100 美元/月），不是原来的 SuperGrok；本店也能充 Super（¥749），在下单页选档位。

**Q：我已经是 SuperGrok 会员，能续费吗？**
A：不能。商品页写明账号不是会员（免费版）才能充，已是付费会员的账号充不了。

**Q：用手机能开吗？**
A：下单付款用手机可以，但复制 sso 代码要用电脑浏览器。

**Q：会自动续费吗？**
A：不会。代充不绑你的卡，用一个月买一个月。

**Q：能找 xAI 退款吗？**
A：不能。付款不是你本人完成的，有问题按本店售后规则处理。
