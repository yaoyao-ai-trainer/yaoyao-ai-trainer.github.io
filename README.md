## 国内开通的四种方法（四家通用）

每家产品的细节（官方原文、条件、风险）在各章里；这里只放通用的横向比较。

- **方法一：官方网页订阅。** 用信用卡在 chatgpt.com / claude.ai / Google 账号 / grok.com 直接订。最正规，订阅、发票、退款都在官方；缺点是国内发行的卡经常付款失败，反复重试更难通过，官方价另加税，用人民币卡付外币还可能有货币转换费。
- **方法二：苹果 / 谷歌应用内购。** 在官方 App 里升级，用应用商店账号的付款方式或余额付款，价格以商店当地显示为准。订阅由苹果 / 谷歌管理，取消和退款都走商店；同一个账号在网页和 App 各订一份会被重复扣费（[OpenAI：如何避免被重复扣费](https://help.openai.com/en/articles/20001043-how-do-i-avoid-being-charged-twice-if-i-subscribe-to-chatgpt-on-ios-android-and-the-web)）。
- **方法三：礼品卡。** OpenAI 有官方 ChatGPT 礼品卡，但只在美国销售和兑换、只能在 chatgpt.com/redeem 网页兑换；Anthropic 的赠送订阅目前暂停购买；Google、xAI 没查到官方专用礼品卡。网上远低于面值的礼品卡常见是盗刷来的，兑换后余额可能被冻结。
- **方法四：代充（第三方代付）。** 由第三方卖家替你付款，把会员开到**你自己的账号**上。支付宝 / 微信就能付，不用自己的卡，不会自动续费；但不是官方渠道，不能找官方退款，售后全靠卖家。xAI 定价页 FAQ 写明不授权任何经销商或第三方卖家；OpenAI 帮助文章写明禁止共享账号凭证和转售访问权限。代充开在你自己的账号上，和"共享账号"不同，但这个风险要自己衡量。

| | 官方网页订阅 | 应用内购 | 官方礼品卡 | 代充 |
|---|---|---|---|---|
| ChatGPT | 要信用卡 | 要外区商店账号 | 只限美国 | 支付宝 / 微信可付 |
| Claude | 要银行卡 | 要外区商店账号 | 暂停销售 | 支付宝 / 微信可付 |
| Gemini | 要 Google 付款方式 | 要商店账号 | 未查到 | 支付宝 / 微信可付 |
| Grok | 要信用卡或借记卡 | 要商店账号 | 未查到 | 支付宝 / 微信可付；官方不授权 |
| 谁管退款 | 官方 | 苹果 / 谷歌 | 官方 | 卖家 |
| 会不会自动续费 | 会，可随时取消 | 会，在商店取消 | 余额扣完为止 | 不会 |

不建议的做法：**合租 / 拼车**（多人共用一个账号，聊天记录别人看得到，额度被分走，多地同时登录容易被风控，通常也违反服务条款）和**成品号**（买别人注册好的账号，随时可能被找回或封掉）。

## 怎么判断代充靠不靠谱：6 个判断点

不管在哪家买都适用（含作者自己的店）。

1. **价格是否正常。** 远低于官方美元价折算的要问清为什么（几十块一个月的常见是退款单、漏洞单，过几天会被收回）；看清"起"字，服务费、发票费是否另算。
2. **要不要账号密码。** 不应该要。要密码、要验证码、要关两步验证、要装软件或插件的，换一家。
3. **多久到账。** 问清是自助还是人工，到账时间有没有说明统计口径。
4. **失败怎么退。** 付款前问清失败后钱或卡密怎么处理：自动退回还是要申请。
5. **掉订阅管不管。** 问清质保覆盖多久、掉了怎么处理（补开、补时长还是退款），要求文字写明。
6. **售后找谁。** 有没有能联系到的真人、订单查询入口，域名能不能在别处核实。

付款前花 1 分钟对照：

- [ ] 页面价格就是要付的全部金额，没有"起"字，也没有另收服务费
- [ ] 不要我的密码、短信或邮箱验证码，也不要我装软件或插件
- [ ] 写明是自助还是人工开通，以及大概多久到账
- [ ] 写明开通失败后钱或卡密怎么处理
- [ ] 写明这一期会员中途掉了怎么补、补多久
- [ ] 有能找到真人的售后，有订单查询入口，域名能在别处核实

有一条答不上来，就先别付款。付款后自检：刷新页面，用你平时的账号看到会员标识、聊天记录都在；到设置里退出所有设备再重新登录；保存订单号和开通截图。

## 常见问题

**Q：ChatGPT / Claude 可以用支付宝、微信吗？**
A：官网不能（ChatGPT 定价页写的是主要信用卡；Claude 以结算页显示的付款方式为准）。用支付宝 / 微信只能走代充，或者间接通过应用商店余额。

**Q：代充开通的会员，能找 OpenAI / Anthropic 退款吗？**
A：不能。付款不是你本人完成的，官方查不到你的付款记录，有问题要找卖家，所以要选找得到人的卖家。

**Q：代充会从我的银行卡自动续费吗？**
A：不会。付款不走你的银行卡，用一个月买一个月，到期前自己再买一次。

**Q：代充要给卖家什么？**
A：账号邮箱；自助开通另需一段登录信息（ChatGPT）、组织 ID（Claude）或 sso 代码（Grok）。不需要密码、验证码、银行卡。要密码的不要用。

**Q：怎么确认开在我自己的账号上？**
A：刷新后用你平时的账号看到会员标识，聊天记录都在；然后在设置里退出所有设备再登录。

**Q：代充会封号吗？**
A：封号看的是钱从哪来和账号怎么用：付款被撤销、多人共用、频繁切换地区、违规内容。开在自己账号、正常渠道付款的代充，和自己绑卡的风险来源是一样的；账号被封一般不在代充质保范围。

**Q：官方有年付吗？**
A：ChatGPT Plus 和 Pro 官方只能月付；Claude 只有 Pro 有年付（一次 200 美元）；Max 只能月付。

**Q：Plus 和 Pro、Pro 和 Max 怎么选？**
A：先买低一档用一个月，一周里好几天撞额度再升。同一账号升级，记录都在。

**Q：SuperGrok 还有吗？**
A：2026 年 10 月 12 日起 xAI 把会员改成三合一，原来的 SuperGrok 对应现在的 Grok Premium（30 美元/月）；新出的 Super（100 美元/月）是更高一档，不是原来的 SuperGrok。

**Q：Claude Code / Codex 要单独买吗？**
A：不用。Claude Code 包含在 Claude Pro / Max 里；Codex 包含在 ChatGPT Plus / Pro 里。都要用开了会员的账号登录才算在会员里。

**Q：ChatGPT 和 Claude 买哪个？**
A：两家入门价都是 20 美元/月。写作、搜索、画图偏 ChatGPT；长文和写代码很多人偏 Claude。
